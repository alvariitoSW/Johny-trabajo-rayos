# Johny-trabajo-rayos

Estudio observacional retrospectivo de **radiómica de las metástasis hepáticas de origen colorrectal** en TC con
contraste en fase portal (LIFEx, o 3D Slicer + SlicerRadiomics + jamovi). Protocolo: `docs/protocolo/protocolo-v0.md`.

- **Reglas del proyecto**: `CLAUDE.md`.
- **Forma de trabajar** (el «plan socialista», traída de `fiebres-neutropenias`): `autonomo/LEEME.md`.
- **Lo pendiente**: `autonomo/BITACORA.md` (sin aprobar) y `autonomo/TABLERO.md` (aprobado).
- **Webs de radiología de referencia**: `autonomo/ideas/webs-radiologia.md`.

**Este repositorio es público: nunca contiene datos de pacientes** (ni imágenes, ni máscaras, ni tablas reales).
Compruébalo con `python3 autonomo/jueces.py` antes de cada commit.
